## What it does

`main.py` writes a single sentence — one small moment of everyday wonder, at most 200 characters — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

## Run

```sh
python3 main.py
```
